# RetroEye

**Bring back the Windows you grew up with.** RetroEye puts the taskbar, Start menu, desktop, folder windows, Control Panel, programs and games of Windows 95, 98, Me, 2000, XP, Vista and 7 back on today's Windows. It's free, and it's built in the open on YouTube, one episode at a time.

## What's in it

- **A taskbar from every era:** Windows 95, 98, Me, 2000, XP (Blue, Olive Green, Silver, Royale and Classic), Vista and 7, with each era's tray, Quick Launch, toolbars, and Flip 3D on Vista and 7.
- **Each era's own Start menu:** the classic cascading menu, XP's two columns, Vista's, and 7's with search.
- **RetroEye desktops** with each era's icons and right-click menus, Active Desktop on 98 to XP, and a My Briefcase that really syncs.
- **Folder windows and Control Panel** for every era: Display Properties, System Properties, Mouse, Sounds, Internet Options, Add or Remove Programs, Help and Support and more.
- **Programs:** GoodEye Explorer, Navigator and Comet (browsers), GoodEye Messenger, GoodEye Media Player and GoodEye Player, Notepad, WordPad, Paint, Calculator, Character Map, Sound Recorder, the Command Prompt, Task Manager, gadgets, and winipcfg (we know it doesn't belong in XP; it's in there because we like it).
- **Games:** Solitaire, FreeCell, Hearts, Spider, Mahjong, Chess, Mines and Pinball.
- **Extras, all optional:** screen savers, era sounds and mouse pointers, a CRT monitor look (off until you switch it on), harmless random blue screens, and share codes to swap setups with friends.

## Install

1. Download **RetroEye-1.0-preview-Setup.exe** from the [1.0 preview release](https://github.com/RetroEye/RetroEye/releases/tag/v1.0-preview).
2. Run it. If it's needed, Setup downloads Microsoft's .NET Desktop Runtime for you.
3. **"Windows protected your PC"?** RetroEye isn't code-signed yet, so Windows doesn't recognize it. Click **More info**, then **Run anyway**.
4. **Blocked with no Run anyway button?** That's Smart App Control, which is on for some brand-new Windows 11 PCs. It blocks programs that aren't code-signed, and RetroEye isn't signed yet. **We plan to sign it soon (hopefully!)**, and then it'll install there too.

RetroEye installs just for you, with no admin rights needed. You can remove it from **Settings > Apps** like any other program. Installing over an older version keeps your settings. Prefer no installer? The release also has a portable zip (it needs the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)).

### System requirements

- **Windows 10 or 11**, 64-bit, 32-bit or ARM; or **Windows 7 SP1 or 8.1** (included, not yet tested on real 7 or 8.1 machines).
- The .NET Desktop Runtime (Setup gets it for you).
- Microsoft Edge WebView2 for the browsers and Active Desktop (it comes with Windows 10 and 11).
